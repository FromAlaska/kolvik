A scene is a short script in workshop/scenes/ that builds something and animates it. It starts from a small template.

How the workshop works

The preview runs the game's own code: every function in src/js/ is loaded, the game just doesn't start. A scene (left, top) builds something with that code and animates it.

Edit a scene and press Ctrl+Enter to run it straight away, or Ctrl+S to save. Edit game source (left, bottom) and save: the server rebuilds the game and the preview reloads with your change, keeping the camera, parameters and scene. Saving a file from your own editor (VS Code and so on) does the same. Syntax errors are caught before the preview reloads and shown with their file and line.

add(obj, x, y, z)put a THREE object in the scene; returns it
params({...})controls in the Parameters tab: speed:[8,1,20] slider · coat:'#5a6a4a' colour · armor:true toggle · gun:['akr','makar'] list. Read them as p.speed. A value read while building rebuilds the scene when you change it; one read in onUpdate changes live.
onUpdate((dt, t) => …)runs every frame (dt seconds, t scene time)
keyskeys held while the preview has focus: keys.KeyW, keys.Space
log(…)print to the Console tab
frame(obj)point the camera at something
inRaid(() => …)call a game function that expects a raid (it reads R), e.g. inRaid(() => animDead(e, dt))
hex('#rrggbb')colour parameter → the number the game's builders take
ws.camera, ws.controls, ws.scene, ws.THREEthe camera, orbit controls, the scene's root group, three.js
game codehumanoid(), walkAnim(), buildGun(), planeModel(), sledModel(), heliModel(), MC(), M('crate'), ITEMS, EK, sfxShot()…

Preview: drag to orbit, right-drag to pan, wheel to zoom. Click a part to select it; the Scene tree tab shows its position, rotation and scale (live, and you can type new values to try them; Copy as code gives you the line to paste). Pivots marks the groups the game rotates to animate. Game look renders at the game's 300-pixel height with its vertex wobble. The time slider jumps to a moment: it rebuilds the scene and plays it forward.

Keys (when not typing): P play/pause · . one frame · R restart · F frame.
